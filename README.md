# sahilaukhaj.github.io

Portfolio and resume of **Sahil Aukhaj**, Software Engineering student at the University of Technology, Mauritius.

- Live site: https://sahilaukhaj.github.io
- Resume (PDF): [assets/Sahil_Aukhaj_Resume.pdf](assets/Sahil_Aukhaj_Resume.pdf)

## Stack

Static HTML, CSS and vanilla JavaScript with no build step.

- [GSAP](https://gsap.com/) + ScrollTrigger for scroll animations and [Lenis](https://github.com/darkroomengineering/lenis) for smooth scrolling (loaded from jsDelivr)
- Google Fonts: Barlow, Barlow Condensed, JetBrains Mono, Silkscreen
- Respects `prefers-reduced-motion`; content stays visible if the scripts fail to load
- Visual style inspired by [filmbot.com](https://filmbot.com/)

## Structure

```
index.html          page markup
css/style.css       tokens, type, buttons, preloader, ticker, menu, hero, intro
css/sections.css    experience, work, skills, education, resume, contact, footer
js/main.js          animations and small UI helpers
assets/             resume PDF and optimised images
```

## Run locally

```bash
python -m http.server 8765
```

Then open http://localhost:8765.

## Updating the resume

The PDF and its preview image are generated by `build_resume.py` (kept in `../resume-source`, outside this repo). Edit its `CONTENT` section, run `python build_resume.py`, then commit the regenerated `assets/Sahil_Aukhaj_Resume.pdf` and `assets/img/resume-preview.png`.
